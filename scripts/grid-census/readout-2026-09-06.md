## Cells with no enforcement check

The issue's dispatch text carried forward #580's "last measured: versioning, attribution,
repository, portability" from PR #582's 2026-09-05 report. That has already partially closed:
`scripts/checks.json` gained a `portability`-cell check (`governance-seed-drift`,
srs#550/#548/#553) since cycle two, unrelated to this programme. **Current state: three cells
carry zero checks** — versioning, attribution, repository — against 48 checks total (up from the
42 PR #582 measured), 19 of which sit in `conformance` alone.

For each, the smallest honest check — narrow enough to be mechanical, not a judgment call:

- **versioning** (2 corpus statements: `rfc-decision-2a1e1590`,
  `04-2-4-2-field#r2`). The corpus's own tradeoff is narrow: a Field's `allowedValues` change
  requires a version increment. Smallest check: for every Field record, diff its committed
  history — if `fieldType`'s value-domain (`allowedValues`) changed between two commits touching
  the same `id`, `version` must have increased. A structural diff over git history, no semantic
  judgment.
- **attribution** (3 statements: `I-133`, `rfc-decision-16b20c56`,
  `07-6-ext-views-l1#r19`). The narrowest of the three is `I-133`'s own shape rule: wherever a
  `fieldMeta` block is present in `fieldValues`, it is exactly `{source, editedAt, sourceRefs}` —
  a structural key-subset validation, mirroring checks the repo already runs for other shapes.
  `07-6-ext-views-l1#r19` (every diagnostic names its rule, instance and field) is a second
  candidate but requires inspecting diagnostic *emission* sites rather than data shape — a bigger
  unit than this one.
- **repository** (12 statements, the least-thin of the three uncovered cells). The
  cell's core claim, stated three times over (`I-80`, `I-49`/`50` via RFC-038, `07-15-ext-repository#r1`),
  is that the tree-enumerated instance set is the sole authoritative catalog and there is no
  manifest index. Smallest check: assert no `manifest.json` under any repository root (or test
  fixture) carries a legacy `instanceIndex` key — mechanical grep-and-parse, directly guards the
  RFC-038 [R1]/[R2] retirement this cell's statements keep citing.

These are proposals for the owner's backlog, not implemented here — Door: non-normative, no
conformance-rule changes in this unit.
