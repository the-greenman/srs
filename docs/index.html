srs.semanticops.com

SRS (pronounced "source") is an open standard for portable semantic documents that people and AI can both understand and use.

Read the explanation at semanticops.com. Agents start at semanticops.com/llms.txt. This site is the reference: the specification and the JSON Schemas.

Specification

  • spec/srs-spec.md the normative specification
  • spec/srs-unified.md the specification with its rationale, in one read

The specification as an SRS repository: srs-spec.srs (open it with any SRS client).

For the concepts, read the model.

JSON Schemas

Each file is served at /schema/2.0/<name>.json, and that URL is the schema's $id. See the schema notes.
